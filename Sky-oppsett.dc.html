Sky-oppsett

Pitch Studio på database i stedet for én maskin

Fire steg. Når de er gjennom ligger pitcher, faktabase, priser og bilder i Supabase, hele teamet logger inn med egen konto, og klientlenkene er passordbeskyttet.

1

Koble til prosjektet

{{ step1Label }}

Supabase → Project Settings → API. Lim inn Project URL og anon public key.

2

Lag tabellene

{{ step2Label }}

Åpne supabase/schema.sql i prosjektet, kopier alt, og kjør det i Supabase → SQL Editor. Det lager tabeller, radsikkerhet, passordsjekk, sporing og bildelageret. Trygt å kjøre på nytt senere.

3

Logg inn

{{ step3Label }}

Første gang: lag kontoen din her. Deretter legger du til resten av selgerne i Supabase → Authentication → Users. Alle innloggede ser alle pitcher.

4

Flytt dataene inn

{{ step4Label }}

Bildene lastes opp rett fra denne nettleseren til Supabase, så de store filene slipper å gå gjennom noe mellomledd. Kjøres én gang, fra maskinen der pitchene ligger i dag.

Etterpå

  • Sett passord per pitch i redigeringsflaten — klienten må skrive det inn før de ser noe.
  • Varsel når en klient åpner: legg Slack-webhooken din i tabellen app_settings, rad open_webhook_url.
  • Skriv URL og nøkkel inn i supabase-config.js før du deler appen, så slipper alle andre steg 1.
  • Når alt er verifisert i skyen kan du trygt tømme nettleserlagringen på maskinen.
